# Deer Camp

A private, offline-first web app that works as a yearly yearbook for a hunting crew's trip.

- Read `docs/BRIEF.md` first. It is the source of truth for scope.
- The team's agents are in `.claude/agents/`: `project-manager`, `builder`, `researcher`, `designer`.
- Start each work session with the `project-manager`, which plans the work and routes it to the others.
- Planning docs: `docs/ROADMAP.md` (tasks and status), `docs/DECISIONS.md` (decision log), `docs/research/`, `docs/design/`.
